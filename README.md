# NovelLex Training (private)

Private training workspace for NovelLex. Keep original EPUBs and derived annotated passages in this **private** repository only. Never copy them to public NoveLA_float.

The first pilot trained GLiNER2.5 Small on synthetic examples only. Its 26-sentence comparison showed F1 base 0.4375 vs LoRA 0.428571; this is **not** a quality improvement.

This repository starts with a guarded data preparation and training pipeline. Real novel text is not committed yet. Source EPUBs and independently checked labels must be supplied before a genuine model-quality claim.

Privacy: GitHub private repository access is controlled by GitHub collaborators, not encryption. GitHub Actions logs and artifacts remain visible to people with repository access. Do not print source passages or token values into logs.
